# LeadFlow Med Spa

Static website for a U.S. med-spa lead-conversion service.

## Before deploying

Replace every occurrence of:

- `leadflowmedspa.vercel.app`
- `hello.leadflowmedspaa@gmail.com`

with your actual Vercel domain and business email.

## Deploy on Vercel

1. Upload this repository to GitHub.
2. Open Vercel and import the GitHub repository.
3. Framework preset: Other / Static.
4. Build command: leave empty.
5. Output directory: `.` or leave default.
6. Deploy.

## SEO / AI discovery

This site includes:
- semantic HTML
- page titles and descriptions
- canonical URLs
- Open Graph metadata
- JSON-LD structured data
- sitemap.xml
- robots.txt
- llms.txt
- crawl access for OAI-SearchBot and ClaudeBot

Being crawlable does NOT guarantee inclusion or ranking in ChatGPT, Claude, Google, or other AI/search systems. The main growth lever is useful, original content and reputable references/links.
